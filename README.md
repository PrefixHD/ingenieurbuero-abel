# Ingenieurbüro Abel – Website

Statische Website mit HTML, CSS und JavaScript. Keine Build-Schritte und keine
Laufzeit-Abhängigkeiten. Schriften und Bilder werden lokal bereitgestellt.

## GitHub Pages
In den Repository-Einstellungen unter Pages „Deploy from a branch“ auswählen,
Branch `main`, Verzeichnis `/(root)` verwenden. Besucher benötigen kein Konto.

## Redaktioneller Stand
Entwurf. Leistungsumfang, Projektzuordnung, Bildrechte, Qualifikationen und
erforderliche rechtliche Angaben sind vor dem regulären Unternehmensauftritt
abschließend zu prüfen. Die Suchmaschinenindexierung bleibt vorerst deaktiviert.

Das Anfrageformular erstellt ausschließlich eine lokale Textdatei und versendet
keine Daten an einen Server. Kontakt ist per Telefon und E-Mail möglich.

Die Website-Dateien lassen sich unabhängig von ChatGPT und VS Code auf jedem
statischen Webhosting verwenden. Schriftlizenz: assets/fonts/OFL.txt.
